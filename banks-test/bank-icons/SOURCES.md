# Джерела іконок банків

Іконки потрібні лише для ідентифікації банківських застосунків на тестовому стенді.

- `abank.webp`, `akord.webp`, `alliance.webp`, `alt.webp`, `bank34.webp`,
  `ca.webp`, `freebank.webp`, `globus.webp`, `grant.webp`, `izi.webp`,
  `kredo.webp`, `mono.webp`, `mtb.webp`, `ob.webp`, `otp.webp`,
  `pivdenny.webp`, `pravex.webp`, `privat24.webp`, `privat24biz.webp`,
  `procredit.webp`, `pumb.webp`, `rada.webp`, `raif.webp`, `sense.webp`,
  `ugb.webp`, `ukrsib.webp`, `ukrsibbiz.webp`, `unex.webp`, `vst.webp`,
  `winbank.webp` — Android-іконки, використані на
  <https://pay24.com.ua/pay/K33BZK4NDa> (завантажено 2026-08-27).
- `oschad.webp` — офіційна іконка застосунку «Ощад» з Google Play,
  package `ua.oschadbank.flumo` (завантажено 2026-08-27).

Для звірки складу й оформлення також використані:

- <https://ibanoplata.com/iban-qr/d75975ed4ef044ecac24d32f55905f0c>
- <https://www.iban24.link/pay/8c8bb5779a7b2a0c7610a59586>

`freebank.webp` відповідає застосунку FreeBank Банку Кредит Дніпро
(`com.creditdnepr.mb`). `ugb.webp` відповідає застосунку ЕКОбанк / Укргазбанк.
